# Springboard

Online exam monitoring and integrity analysis system, built during my
Infosys Springboard work. Flask app with candidate registration, webcam
photo capture, login with CAPTCHA, live monitoring through OpenCV face
detection, browser focus logging, integrity scoring and a final report.

Stack: Python, Flask, SQLite, OpenCV, Jinja2 templates.

Run: `pip install -r requirements.txt`, then `python app.py`.
